# Portfolio

Personal portfolio site for Sebastien Kempf, senior web developer. Single-page Next.js app (App Router, React 19, TypeScript, Tailwind CSS v4), deployed on Vercel.

## Development

Requires [pnpm](https://pnpm.io).

```bash
pnpm install
pnpm dev      # http://localhost:3000
```

Content (experience, projects, social links) is defined in typed arrays in `src/app/page.tsx`.
